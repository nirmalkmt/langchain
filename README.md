# LLM Basics & Prompting

This repository contains my hands-on learning and practice with **Large Language Models (LLMs)**.
I explored the **fundamentals of LLMs**, including how prompts, tokens, and model parameters affect outputs.
Practiced different **prompting techniques** such as Zero-Shot, One-Shot, Few-Shot, Role-Based, and Instruction prompting.
Learned about **Output Parsers** to convert LLM responses into structured and usable formats.
Implemented these concepts using **Python and LangChain** through practical examples and experiments.
